# v0.7.1 Release Notes

[简体中文](#简体中文) | [English](#english)

## 简体中文

v0.7.1 版本新增对 `Gemini 4 Neon` 与 `Orchestrator (Neon)` 的完整支持，对齐 Antigravity `v1.5.11+` 官方 `ModelTierConfig` 档位映射规范，并全面重写与精简优化了中英文 `README` 文档。

### 核心特性与变更

1. **完整支持 `Gemini 4 Neon` 与 `Orchestrator (Neon)`**
   - **能力探测与 Payload 推断 (`hasNeon`)**：在模型能力探测与 Payload 推断逻辑中新增 `hasNeon` 识别，覆盖 `gemini-4-neon-low/medium/high/xhigh` 全档位及 `Gemini 4 Neon` 显示名称，确保 Neon 主模型会话下自动启用正确的 Worker 路由策略。
   - **`Orchestrator (Neon)` 原生编排兼容**：将 `Orchestrator (Neon)` 纳入原生编排入口识别，自动激活 **Lite Guard Mode**，在保留超大文件切片、防嵌套、禁轮询、派单契约、命令守门与子代理文件互斥锁的前提下，豁免主控读写文件数量拦截与数量漂移催派。

2. **对齐 AGY `v1.5.11+` 官方 `ModelTierConfig` 档位映射规范**
   - 统一规范 `invoke_subagent` 的模型档位映射：`flash` → `Gemini 4 Hydrogen High`，`[FORCE-PRO]` 下的 `pro` → `Gemini 4 Hydrogen XHigh`，Hydrogen 主会话 `inherit` → 继承 `Gemini 4 Hydrogen`。
   - 同步更新提示词规则与能力路由说明，确保主控与子代理之间的模型路由行为与 AGY `v1.5.11+` 宿主规范完全一致。

3. **全面重写与精简优化中英文 `README`**
   - 全面重写 `README.md` 与 `README.zh-CN.md`，精简冗余表述，突出核心架构（Pro 架构师 + Flash/Hydrogen 助手）、快速安装与免 Git 升级方式、模型路由策略及常用命令参考，提升文档可读性与检索效率。

## English

v0.7.1 adds full support for `Gemini 4 Neon` and `Orchestrator (Neon)`, aligns with the official Antigravity `v1.5.11+` `ModelTierConfig` tier mapping specification, and delivers a comprehensive rewrite and streamlining of both `README.md` and `README.zh-CN.md`.

### Highlights and Changes

1. **Full Support for `Gemini 4 Neon` & `Orchestrator (Neon)`**
   - **Capability Detection & Payload Inference (`hasNeon`)**: Added `hasNeon` detection across capability probing and payload inference, covering `gemini-4-neon-low/medium/high/xhigh` and `Gemini 4 Neon` display names to ensure accurate Worker routing under Neon lead sessions.
   - **Native `Orchestrator (Neon)` Compatibility**: Added `Orchestrator (Neon)` recognition to automatically enable **Lite Guard Mode**, exempting lead read/write file count limits and drift nudges while preserving large-file slicing, anti-nesting, anti-polling, dispatch contracts, command guarding, and subagent file mutex locks.

2. **Alignment with AGY `v1.5.11+` Official `ModelTierConfig` Tier Mapping**
   - Standardized `invoke_subagent` tier mappings: `flash` → `Gemini 4 Hydrogen High`, `pro` (under `[FORCE-PRO]`) → `Gemini 4 Hydrogen XHigh`, and `inherit` in Hydrogen lead sessions → inherits `Gemini 4 Hydrogen`.
   - Updated rule prompts and capability routing documentation to stay fully aligned with AGY `v1.5.11+` host specifications.

3. **Streamlined & Rewritten `README.md` and `README.zh-CN.md`**
   - Rewrote and condensed both English and Simplified Chinese READMEs to highlight the Pro Architect + Flash/Hydrogen Worker workflow, quick installation and git-free updates, model routing strategies, and verification commands for clearer onboarding.
