# v0.6.0

本次更新兼容 Antigravity 的原生 Orchestrator (Argon)，修复终审切片抽检与跨平台工具匹配，并为子代理自检增加可核对的命令轨迹。

- **AGY 启动路由**：仅 SessionStart 探测 `agy models`，同一父进程 <12 小时、跨终端 <1 小时复用 capabilities.json；后续 Hook 只读缓存。Hydrogen 主会话使用合法枚举 `Model="inherit"`，Argon / Carbon / Opus 等主会话默认 `Model="flash"`。仅显式 PRO_HYDROGEN_ID 且有 Hydrogen 能力时覆盖自定义 ID，任务配置优先；CLI 不可用可从 Gemini 4 主模型推断。Flash 主会话允许普通读取 6 个文件、直改 4 个文件，子代理不触发放宽策略。
- **Lite Guard Mode**：modelName / model 匹配 orchestrator，或设置 PRO_NATIVE_ORCHESTRATOR=1 时，豁免主模型读写文件数量限制和数量漂移催派。超大文件切片、防嵌套、禁轮询、派单契约及命令守门继续生效。
- **Audit 额度**：初始 phase=explore、auditSliceQuota=0；每次放行 self 派单增加 2 次额度，上限 10。明确起止行号的 ≤80 行切片优先原子扣减，可跨文件连续抽检；新用户轮次清零，耗尽后恢复普通读取配额。超大压缩行仍受读取保护。
- **模型与 Matcher**：Codex 默认 Worker 统一为 gpt-5-mini，保留已有自定义配置；PRO_RESEARCH_MODEL / PRO_SELF_MODEL 优先于通用 Worker。实际选中模型仍须通过 Codex 提供方验证。根 hooks.json 与 Claude / Codex 适配 Matcher 补齐原生工具名，输出转换保留任务专用模型。
- **子代理证据**：父子会话各保留最近 10 条脱敏命令摘要和时间戳，以批次标识隔离旧证据；无本批命令记录时温和提醒核实四列表格自检。记录失败会写入决策日志。Codex 的 SubagentStop 同步调用终审提示。
- **兼容修复**：超过 64 KB 的 SYSTEM 转录首行仍可识别 FLASH-WORKER、PRO-CONTRACT、ARGON-CONTRACT；显式用户来源保持主会话身份。PRO_TEST 和 ARGON_TEST 均标记测试日志。
- **父子关联与互斥锁**：父 ID 可从转录 sender、派单契约 PRO-PARENT 或 last_spawn.json 恢复；多个候选父会话不按时间猜选。父 Session 锁内原子认领 batchFileClaims，多文件冲突不留下部分认领，新批次释放、同批续派保留。AGY 父 ID 缺失或状态持久化失败时拒绝源码写入，避免未受保护的并行修改。
- **省流估算**：report 共用 STATE_DIR / LOG_FILE，汇总启动 strategy；区分轮询、并发超限、递归、文件冲突、配置保护和状态失败。按真实拒绝与切片实际请求/保留行数估算 KB / Token，忽略 shadow 假设节省，以 4 bytes/token 换算。Codex 独立包新增 `node report.mjs` 入口。
- **发布契约**：根 SKILL.md / AGENTS.md 与规范目录同步，自动断言镜像与三套旧版 Matcher 一致；运行包排除本地 capabilities.json，部署保留已有能力缓存。doctor 末尾重新读取宿主能力摘要；并发测试退出时清理临时状态。

PreToolUse 轨迹证明命令已提交并获放行，不证明进程执行成功；测试通过仍需核对实际输出与退出状态。此次验证使用隔离状态和离线协议夹具，不包含真实宿主联网验收。
