## 简体中文

v0.7.3 版本重点落地**方案 A（纯只读 `research` 双轨验收契约）**并修复审计发现的核心逻辑、跨平台同步与版本号硬编码问题，进一步提升多代理并发调研与工程自检的稳定性。

### 核心特性与修复

1. **纯只读双轨契约与并发精确判定（方案 A）**
   - **消除并发契约指令冲突**：重写 `【并发调研契约】`，彻底移除要求只读 `research` 代理写 `reports/<task>.md` 的矛盾指令，明确禁止只读探路代理尝试写文件；同轮多代理并发调研时仅输出高密度精要矩阵与索引（核心结论、`file:line` 证据、风险隐患、Top 优化建议），杜绝上下文洪泛（如需完整归档由主控或写权限代理汇总落盘）。
   - **独立计数与混派隔离**：在 `scripts/lib.mjs` 与 `scripts/guard-subagent.mjs` 中新增 `currentBatchResearchSpawns`（并在 `pre-invocation.mjs` 与 `codex-hook.mjs` 新轮次边界同步清零），使用锁内精确值 `admittedResearchSpawns` 消除锁外 `readSession` 竞态，避免 `self` 与 `research` 同轮混派误判；支持首单 Prompt 显式标注 `[MULTI-RESEARCH]` 即刻触发并发契约。
   - **冷启动正则补全**：更新 `scripts/lib.mjs` 中 `capabilitySubagent` 与 `isSubAgent` 的契约识别正则，完整支持无 `[FLASH-WORKER]` 前缀时识别 `【深度研报契约】` 与 `【并发调研契约】`。

2. **动态版本号注入与 Codex 双轨同步**
   - **消除硬编码版本号**：`scripts/session-start.mjs`、`scripts/doctor.mjs` 与 `scripts/codex-app-server.mjs` 全面改为从 `scripts/lib.mjs` 导入 `PLUGIN_VERSION`。
   - **Codex 双轨契约同步**：`scripts/codex-hook.mjs` 的 `SubagentStart` 根据 `workerType`（`research` / `self`）分别注入双轨英文契约；同步更新 `SessionStart` 与 `adapters/codex/flash-dev/SKILL.md`。

3. **死循环熔断日志修复、CI 门禁与测试强化**
   - **熔断日志去污**：修复 `scripts/guard-command.mjs` 中死循环熔断分支误传 `payload` 到 `deny()` 导致的重复/对象型 `rule` 日志污染，在 `scripts/test-update.mjs` 中新增 `decisions.jsonl` 断言覆盖。
   - **测试与 CI 闭环**：`.github/workflows/release.yml` 与 `docs/INSTALL.md` 补齐 `test-contract-dual-track.mjs` 门禁；`scripts/test-contract-dual-track.mjs` 扩充至 8 项测试（覆盖纯只读并发契约、混派隔离、`[MULTI-RESEARCH]` 首单标记与冷启动正则识别）。

## English

v0.7.3 delivers **Plan A (strictly read-only `research` dual-track acceptance contracts)** and resolves key concurrency, cross-platform sync, logging, and hardcoded version issues identified during code audit.

### Highlights and Fixes

1. **Strictly Read-Only Dual-Track Contracts & Accurate Concurrent Detection (Plan A)**
   - **Conflict-Free Concurrent Research Contract**: Rewrote `【并发调研契约】` to remove contradictory instructions asking read-only `research` workers to write `reports/<task>.md`. Concurrent read-only research dispatches explicitly prohibit file writes and output a high-density executive summary matrix and index (core conclusions, `file:line` evidence, risks, and top recommendations) to prevent context saturation; full archival, when needed, is persisted by Pro or a write-capable agent.
   - **Dedicated Research Batch Counter & Mix Isolation**: Added `currentBatchResearchSpawns` in `scripts/lib.mjs` and `scripts/guard-subagent.mjs` (reset at new turn boundaries in `pre-invocation.mjs` and `codex-hook.mjs`), using the locked `admittedResearchSpawns` value instead of an unlocked `readSession` re-read to prevent race conditions and false multi-research triggers when mixing `self` and `research` dispatches. Added `[MULTI-RESEARCH]` opt-in tag support on the first dispatch.
   - **Cold-Start Regex Alignment**: Updated `capabilitySubagent` and `isSubAgent` in `scripts/lib.mjs` to recognize `【深度研报契约】` and `【并发调研契约】`.

2. **Dynamic Version Propagation & Codex Dual-Track Sync**
   - **Dynamic `PLUGIN_VERSION`**: Updated `scripts/session-start.mjs`, `scripts/doctor.mjs`, and `scripts/codex-app-server.mjs` to import `PLUGIN_VERSION` from `scripts/lib.mjs`, eliminating hardcoded version drift.
   - **Codex Dual-Track Alignment**: `scripts/codex-hook.mjs` (`SubagentStart` & `SessionStart`) and `adapters/codex/flash-dev/SKILL.md` now emit role-specific dual-track guidance for read-only `research` vs `self` implementation workers.

3. **Thrashing Circuit-Breaker Fix, CI Gate & Expanded Tests**
   - **Clean Audit Logging**: Fixed `scripts/guard-command.mjs` passing `payload` instead of returning `{ decision: 'deny', reason }` on thrashing circuit-breaker denials, backed by new `decisions.jsonl` assertions in `scripts/test-update.mjs`.
   - **CI & Regression Coverage**: Added `scripts/test-contract-dual-track.mjs` to `.github/workflows/release.yml` and `docs/INSTALL.md`, and expanded `scripts/test-contract-dual-track.mjs` to 8 passing tests covering read-only concurrent contracts, mixed-dispatch isolation, `[MULTI-RESEARCH]`, and cold-start `isSubAgent` matching.
