# v0.7.5 Release Notes

[简体中文](#简体中文) | [English](#english)

## 简体中文

v0.7.5 版本重点修复 **Antigravity 2.35.2 下 `Gemini 4 Neon` 主会话子代理派发失败** 的路由问题，确保在最新宿主版本下的多代理协同稳定运行。

### 核心特性与修复

1. **Antigravity 2.35.2 `Gemini 4 Neon` 子代理路由修复**
   - **默认路由调整为 `"inherit"`**：修复在 Antigravity 2.35.2 环境下，`Gemini 4 Neon` 主会话调用 `invoke_subagent` 使用 `"flash"` 别名导致子代理派发失败的问题，改为默认路由至 `"inherit"`。
   - **能力探测与回归验证同步**：同步更新 `scripts/lib.mjs` 路由策略与 `scripts/test-capabilities.mjs` 能力路由测试覆盖，确保 `Gemini 4 Neon` 及其他主模型下的默认派发、显式覆盖与防降级逻辑均通过门禁验证。

2. **完整继承 v0.7.3 全部能力**
   - 保留纯只读 `research` 双轨验收契约（工程实现四列表格 + 深度研报 / 并发精要矩阵防洪泛）、独立 `currentBatchResearchSpawns` 并发计数与 `[MULTI-RESEARCH]` 首单标记、动态 `PLUGIN_VERSION` 注入、Codex 双轨同步、死循环熔断、Audit 动态切片配额与免 Git 一键升级（`scripts/update.mjs`）。

## English

v0.7.5 resolves the **Antigravity 2.35.2 `Gemini 4 Neon` subagent dispatch failure** by updating the default subagent routing strategy for `Gemini 4 Neon` main sessions.

### Highlights and Fixes

1. **Antigravity 2.35.2 `Gemini 4 Neon` Subagent Routing Fix**
   - **Default Routing to `"inherit"`**: Fixed an issue on Antigravity 2.35.2 where `Gemini 4 Neon` main sessions dispatching `invoke_subagent` with the `"flash"` alias failed; `Gemini 4 Neon` main sessions now route subagent dispatches to `"inherit"` by default.
   - **Capability & Regression Verification**: Updated routing logic in `scripts/lib.mjs` and capability tests in `scripts/test-capabilities.mjs` to verify default `"inherit"` routing and guard behavior across all test suites.

2. **Preserves All v0.7.3 Capabilities**
   - Retains the strictly read-only `research` dual-track acceptance contracts (4-column engineering table + deep research / concurrent executive matrix), dedicated `currentBatchResearchSpawns` and `[MULTI-RESEARCH]` tracking, dynamic `PLUGIN_VERSION` propagation, Codex dual-track sync, thrashing circuit breaker, Audit dynamic slice budget, and git-free upgrades (`scripts/update.mjs`).
