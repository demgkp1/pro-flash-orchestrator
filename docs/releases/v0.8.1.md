# v0.8.1 Release Notes

[简体中文](#简体中文) | [English](#english)

## 简体中文

v0.8.1 版本聚焦 **可视化面板双语化、名称统一、更新请求超时修复、运行态信息透明化与极窄侧边栏适配**，完整保留 v0.8.0 的统一档位设置、自动路由与 `pro` 授权门禁。

### 核心特性与修复

1. **统一插件与面板显示名称为 `Pro-Flash Orchestrator`**
   - 将 `sidecars/panel/sidecar.json`、`index.html`、`app.js` 与 `i18n.js` 中的面板名称和页面标题统一为 `Pro-Flash Orchestrator`，与插件清单 `plugin.json` 保持一致。

2. **可视化面板新增零依赖中英双语**
   - 新增 `sidecars/panel/i18n.js`，支持面板右上角 `中 / EN` 一键切换，并按 URL `?lang=` → `localStorage`（`pfo.panel.lang`）→ 浏览器 `navigator.language` 顺序自动检测语言且持久化保存。
   - 错误响应与安装不可更新原因通过结构化 `code` / `reasonCode` 本地化映射展示，面板更新后锁定提示同样支持双语切换。

3. **修复 `/api/update` 15s 请求超时小于 30s 下载超时的隐藏问题**
   - 将 `sidecars/panel/main.mjs` 的 HTTP `server.requestTimeout` 由 `15_000` ms 提升至 `60_000` ms（高于内部 30s 下载超时），避免面板触发在线更新下载时连接被服务层提前中断。

4. **增强面板信息透明度**
   - `/api/state` 透出只读运行态探测信息（`runtime.hasHydrogen`、`runtime.capabilitySource`、`runtime.hydrogenId`）与后台更新缓存（`updateCheck.latestVersion`、`releaseUrl`、`checkedAt`）。
   - 面板外显自动路由下的 Hydrogen 探测状态提示、环境变量覆盖横幅提醒（`PRO_RESEARCH_MODEL` / `PRO_SELF_MODEL` / `PRO_WORKER_MODEL` 等）以及已知新版本与 Release 链接展示。

5. **优化 `< 400px` 极窄侧边栏响应式布局**
   - 针对 `< 400px` 侧边栏窄屏优化样式：长安装路径改为单列堆叠布局防止挤压溢出，顶栏（品牌标识与语言切换/版本徽章）支持自适应换行，标题启用 `overflow-wrap: anywhere`。

## English

v0.8.1 focuses on **bilingual UI support, consistent naming, `/api/update` server timeout alignment, runtime transparency, and narrow-sidebar responsiveness**, while preserving all v0.8.0 unified tier settings, automatic routing, and the `pro` authorization gate.

### Highlights and Fixes

1. **Unified Plugin & Panel Display Name (`Pro-Flash Orchestrator`)**
   - Standardized panel titles and display names across `sidecars/panel/sidecar.json`, `index.html`, `app.js`, and `i18n.js` to `Pro-Flash Orchestrator`, matching `plugin.json`.

2. **Zero-Dependency Bilingual Side Panel (`中 / EN`)**
   - Added `sidecars/panel/i18n.js` with a top-right `中 / EN` switcher, automatic language detection (`?lang=` query parameter → `localStorage` key `pfo.panel.lang` → `navigator.language`), and persistent storage.
   - Localized structured API `code` and install `reasonCode` diagnostics as well as the post-update reload lock banner.

3. **Fixed `/api/update` 15s Request Timeout Being Shorter Than 30s Download Timeout**
   - Raised `server.requestTimeout` in `sidecars/panel/main.mjs` from `15_000` ms to `60_000` ms so online release downloads (up to 30s) are not prematurely aborted by the local HTTP server.

4. **Improved Runtime & Update Transparency**
   - Extended `/api/state` with read-only runtime capability state (`runtime.hasHydrogen`, `runtime.capabilitySource`, `runtime.hydrogenId`) and cached update metadata (`updateCheck.latestVersion`, `releaseUrl`, `checkedAt`).
   - Surfaced live Hydrogen detection hints under Auto mode, active environment variable override banners, and latest known GitHub Release version links directly in the panel.

5. **Responsive Layout Polish for Narrow Sidebars (`< 400px`)**
   - Stacked long installation path rows into single-column layout below `400px`, enabled flexible wrapping in the masthead header, and applied `overflow-wrap: anywhere` to titles.
