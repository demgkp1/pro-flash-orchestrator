# v0.7.0 Release Notes

[简体中文](#简体中文) | [English](#english)

## 简体中文

v0.7.0 版本引入了零阻塞后台版本更新检测与免 Git 一键在线升级能力，新增子代理死循环熔断器（Thrashing Circuit Breaker），并对 Antigravity 模型探测、子代理合法枚举校验、PowerShell 管道别名识别以及跨平台安装稳定性进行了全面强化。

### 核心特性与变更

1. **零阻塞后台版本检测与免 Git 一键在线升级**
   - **后台更新检测 (`check-update-worker.mjs`)**：在 `SessionStart` 阶段异步静默检测 GitHub Releases 最新版本，结果缓存至 `.state/update-check.json`，会话启动零网络延迟；在检测到新版本时以 UI 卡片优雅提醒，支持通过环境变量 `PRO_NO_UPDATE_CHECK=1` 完全禁用检测。
   - **免 Git 一键升级 (`scripts/update.mjs`)**：普通 Release 用户无需配置 Git 仓库或手动拷贝源码，执行 `node "<插件安装目录>/scripts/update.mjs"` 即可自动拉取最新精简 Release 资产包（`pro-flash-orchestrator-antigravity-v*.zip`）覆盖升级。升级过程严格进行父目录防逃逸检查、防符号链接攻击，并 100% 保护与保留用户的 `.state/` 状态目录及配置。同时支持 `--zip <path>` 本地离线包升级与 `--dry-run` 预览。

2. **子代理死循环熔断器 (Thrashing Circuit Breaker)**
   - 针对执行助手遇到报错时陷入无限重试死循环、徒增 Token 消耗与上下文污染的问题，新增物理熔断拦截机制。
   - 在命令守门（`guard-command.mjs`）中实时追踪子代理执行历史：当检测到子代理在同一任务批次内连续重复执行相同失败命令达到上限（由环境变量 `PRO_THRASH_LIMIT` 配置，默认 3 次，即连续失败重试 2 次）时，触发硬拦截（`deny`），物理熔断重试循环，强制子代理停止工具调用并按四列表格将错误与行号如实汇报给 Pro 主控架构师接管修复。

3. **AGY 模型探测超时修复与枚举安全保护**
   - **探测超时优化**：将 `agy models` 探测超时阈值放宽至 `5500ms`；在 Windows 平台下直接通过 `cmd.exe /c agy.cmd models` 调用批处理脚本，彻底解决因子进程直接执行 `.cmd` 抛错及重试超时导致的探测失败问题。
   - **枚举安全保护**：引入 `INVOCABLE_SUBAGENT_MODELS` 白名单集合（严格限制为 `inherit`、`flash_lite`、`flash`、`pro` 四个合法枚举），对环境变量传入的候选 Worker 模型执行严格合法性校验，杜绝非法模型标识符导致的派单异常。

4. **PowerShell 管道别名识别与系统稳定性增强**
   - **`select` 管道别名识别**：在命令守门中将 PowerShell 常用别名 `select`（对应 `Select-Object`）纳入受保护的管道截断与只读管道判定逻辑，精准识别 `-First` / `-Last` 截断参数。
   - **防空骨架父会话创建**：在子代理命令证据回写父会话时引入 `sessionExists` 存在性检查，防止在缺少父会话时自动生成只有空骨架的无意义父状态文件。
   - **换行符归一化比对**：在 `scripts/install.mjs` 中增加 CRLF 与 LF 跨平台换行符归一化比对逻辑，避免因换行符差异导致的文件误判变更与不必要覆写。

## English

v0.7.0 introduces zero-latency background update checks and git-free one-click runtime updates, adds the Thrashing Circuit Breaker to prevent repetitive subagent retry loops, and hardens AGY model capability detection, legal enum validation, PowerShell pipeline alias parsing, and cross-platform install stability.

### Highlights and Changes

1. **Non-blocking Background Update Checks & Git-free One-click Updater**
   - **Background Update Checker (`check-update-worker.mjs`)**: Asynchronously checks GitHub Releases for new versions during `SessionStart` without adding startup latency. Caches metadata in `.state/update-check.json` and renders an update banner. Can be disabled anytime via `PRO_NO_UPDATE_CHECK=1`.
   - **In-place Runtime Updater (`scripts/update.mjs`)**: Release users without Git can update directly by executing `node "<install-dir>/scripts/update.mjs"`. It automatically fetches the latest official minimal release archive (`pro-flash-orchestrator-antigravity-v*.zip`), validates against path-traversal and symlink attacks, unpacks and replaces runtime files, and 100% preserves `.state/` and user configurations. Also supports `--zip <path>` for offline updates and `--dry-run` to preview changes.

2. **Subagent Thrashing Circuit Breaker**
   - Prevents subagents from endlessly retrying identical failing commands, exhausting tokens and degrading context.
   - Enforced in `guard-command.mjs`: when a subagent executes the same failing command consecutively up to the limit (configured by `PRO_THRASH_LIMIT`, default 3 times, i.e., 2 failed retries), a physical `deny` is triggered. The subagent is commanded to stop tool execution immediately and report the error in a 4-column table for the Pro lead architect to take over.

3. **AGY Model Probe Timeout Fix & Safe Subagent Model Enums**
   - **Probe Timeout Hardening**: Relaxed the `agy models` probe timeout to `5500ms`. On Windows, it invokes `cmd.exe /c agy.cmd models` directly to eliminate `.cmd` execution failures and secondary retry timeouts.
   - **Invocable Model Safety**: Added `INVOCABLE_SUBAGENT_MODELS` guard restricting subagent models to valid Antigravity lowercase enums (`inherit`, `flash_lite`, `flash`, `pro`), rejecting illegal model IDs from environment overrides.

4. **PowerShell Pipeline Aliases & Installation Stability**
   - **`select` Alias Recognition**: Added recognition for the PowerShell `select` alias (`Select-Object`) in bounded pipeline slicing (`-First`/`-Last`) and read-only mode inspection.
   - **Skeleton Session Prevention**: Added `sessionExists` guard before recording child command admissions to the parent session, preventing creation of empty skeleton parent session state files.
   - **Newline-Normalized Install Comparison**: `scripts/install.mjs` normalizes CRLF and LF when comparing existing and new files, preventing spurious file overwrites across different operating systems.
