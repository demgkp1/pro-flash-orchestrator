## 简体中文

v0.7.2 版本正式引入双轨验收契约架构（Dual-Track Acceptance Contracts），彻底解耦工程实现与认知调研的验收规范与交付要求；支持并发扇出调研动静分离与报告落盘机制；强化多平台规范镜像同步与专有回归测试套件。

### 核心特性与变更

1. **双轨验收契约架构（Dual-Track Acceptance Contracts）**
   - **工程实现轨（`self` / `[FLASH-WORKER]`）**：自动注入四列表格汇报契约（`| 文件绝对路径 | 起止行号 | 核心变更 | 自检命令与结果 |`）与多代理并发边界红线（专属写入互斥隔离、单文件局部测试）。严禁聊天窗口大段源码回贴（单段 ≤10 行），完整长文与技术分析必须写入 artifact 目录。
   - **认知调研轨（`research` 典范长文）**：彻底废除旧版“摘要不超过 30 行”的死板字数限制。单代理探路派单自动注入【深度研报契约】，要求按典范报告格式深度剖析关键模块、列举具体文件与行号事实证据、诊断核心薄弱环节与风险瓶颈、产出高价值 Top 优化建议，直接在消息中完整结构化交付。

2. **并发扇出动静分离与报告落盘（Concurrent Fan-Out Dynamic/Static Separation）**
   - 在同轮多代理并发调研场景下，契约智能切换为【并发调研契约】。
   - 驱动子代理将长篇深度研报落盘至 `reports/<task>.md`，聊天消息中仅保留核心结论速查、关键文件与行号证据、风险隐患与 Top 优化建议的精要矩阵与建议索引，消除多子代理并发汇报对主会话上下文的洪泛冲击。

3. **规范镜像同步与测试强化**
   - 确保根目录镜像文件（`SKILL.md` ↔ `skills/flash-dev/SKILL.md`、`AGENTS.md` ↔ `rules/AGENTS.md`）保持严格的字节级与换行符一致性。
   - 新增 `scripts/test-contract-dual-track.mjs` 测试套件，全覆盖验证单代理深度研报契约注入（验证无 30 行限制）、多代理并发研报契约注入、工程实现四列表格与并发红线、追加消息（`send_message`）提醒更新以及 `define_subagent` 深度研报注入。

4. **完整继承 v0.7.0 全部守门与自愈能力**
   - 零阻塞后台更新检测与免 Git 一键升级（`scripts/update.mjs`）。
   - 子代理死循环熔断器（Thrashing Circuit Breaker），防止失败命令死循环重试。
   - AGY 模型能力探测、枚举白名单校验（`inherit`、`flash_lite`、`flash`、`pro`）与原生 Orchestrator Lite Guard Mode 兼容。

## English

v0.7.2 officially introduces the Dual-Track Acceptance Contract architecture, cleanly decoupling engineering code implementations from cognitive research explorations; introduces concurrent fan-out dynamic/static separation with report landing; and reinforces spec mirror synchronization and regression testing.

### Highlights and Changes

1. **Dual-Track Acceptance Contracts**
   - **Engineering Implementation Track (`self`)**: Injects the structured 4-column table contract (`| File Absolute Path | Line Range | Core Changes | Self-Test Command & Result |`) and concurrency safety boundaries (file mutex isolation, local unit testing). Inline source code dumps are strictly prohibited (single snippets ≤10 lines), and full analyses are directed to the artifacts directory.
   - **Cognitive Research Track (`research` Paradigm Report)**: Formally abolishes the rigid legacy 30-line truncation constraint. Single `research` dispatches inject the structured Deep Research Paradigm (`【深度研报契约】`), requiring comprehensive module dissection, line-number factual evidence, risk/bottleneck diagnosis, and top actionable recommendations delivered directly in the message.

2. **Concurrent Fan-Out Dynamic/Static Separation**
   - For multi-agent concurrent research batches within the same turn, dispatches dynamically switch to `【并发调研契约】`.
   - Directs subagents to persist full-length research reports to `reports/<task>.md` while keeping the chat response focused on an executive summary matrix and recommendation index, preventing conversation context saturation during concurrent multi-agent executions.

3. **Spec Mirror Synchronization & Test Suite Reinforcement**
   - Enforces strict byte-level and newline synchronization between root mirror files and canonical definitions (`SKILL.md` <-> `skills/flash-dev/SKILL.md`, `AGENTS.md` <-> `rules/AGENTS.md`).
   - Adds `scripts/test-contract-dual-track.mjs` covering single depth research contracts (verifying removal of the 30-line limit), multi-agent concurrent research contracts, engineering 4-column table contracts, and `send_message` reminders.

4. **Preserves All v0.7.0 Guards & In-place Upgrades**
   - Non-blocking update checks and git-free runtime upgrades (`scripts/update.mjs`).
   - Subagent Thrashing Circuit Breaker to prevent retry loops.
   - Startup AGY capability detection, model enum whitelist enforcement, and native Orchestrator compatibility.
