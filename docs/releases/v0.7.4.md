# v0.7.4 Release Notes

## 简体中文

v0.7.4 增加 Codex 稳定 Git Marketplace 发布与迁移流程，并修复父会话身份判定和 AGY 更新检测诊断。

### 核心特性与修复

1. **正式 Release 驱动完整包发布**：稳定 GitHub Release 成功后，将同标签的完整 Codex 运行包发布至 `codex-marketplace` 稳定 ref；校验 ZIP 内容、路径和两份插件清单版本。Draft、Prerelease 与旧版本不会覆盖稳定分支。
2. **显式 Local 回退与迁移事务回滚**：Git 安装先检查稳定 ref，失败时保留旧部署；后续迁移失败会回滚 Marketplace 来源、Hook、控制配置与插件状态。本地部署必须显式选择 `--local`。
3. **兼容桥跟随新 Git Snapshot**：兼容桥使用当前配置的新 Git 部署目录，避免继续执行旧 ZIP 快照。
4. **父会话身份修复**：`parent_tool_use_id` 是工具调用关联信息，不再单独触发 Worker 身份判定。
5. **AGY 脱敏诊断**：后台版本检测记录脱敏错误码，不会后台自动安装或升级；升级仍由用户显式运行已安装插件的 `update.mjs`。

### 安装与升级

首次稳定 Marketplace 发布可用后，在源码仓库根目录安装或迁移 Codex：

```powershell
node scripts/install.mjs --platform codex --git
```

需要显式本地回退时，在同一仓库根目录运行：

```powershell
node scripts/install.mjs --platform codex --local
```

AGY 用户运行**已安装插件目录**内的升级工具；以下为默认安装路径，自定义部署请替换为实际路径：

```powershell
node "$HOME/.gemini/config/plugins/pro-flash-orchestrator/scripts/update.mjs"
```

本版包名为 `pro-flash-orchestrator-antigravity-v0.7.4.zip` 与 `pro-flash-orchestrator-codex-v0.7.4.zip`。真实 Codex UI 升级尚未验收，不宣称原生 UI 升级已完整可用。

## English

v0.7.4 adds stable Codex Git marketplace publication and migration, and fixes parent-session classification and AGY update diagnostics.

### Highlights and Fixes

1. **Complete Package Published from a Stable Release**: After a stable GitHub Release succeeds, publish the complete Codex runtime package from the same tag to the stable `codex-marketplace` ref. ZIP contents, paths, and both plugin manifest versions are verified. Drafts, prereleases, and older versions do not replace the stable branch.
2. **Explicit Local Fallback & Transactional Rollback**: Git installation preflights the stable ref and preserves the old deployment on failure. A later migration failure rolls back the marketplace source, hooks, controls, and plugin state. Choose `--local` explicitly for local deployment.
3. **Compatibility Bridge Follows the New Git Snapshot**: The bridge uses the configured new Git deployment instead of executing the old ZIP snapshot.
4. **Parent-Session Identity Fix**: `parent_tool_use_id` correlates tool calls and no longer identifies a session as a worker by itself.
5. **Redacted AGY Diagnostics**: Background version checks record redacted error codes. They do not automatically install or upgrade; users explicitly run `update.mjs` from the installed plugin.

### Install and Upgrade

Once the first stable marketplace publication is available, install or migrate Codex from the source repository root:

```powershell
node scripts/install.mjs --platform codex --git
```

For an explicit local fallback, run from the same repository root:

```powershell
node scripts/install.mjs --platform codex --local
```

AGY users run the updater from the **existing installation**. The default path is shown; replace it with your actual installation path if customized:

```powershell
node "$HOME/.gemini/config/plugins/pro-flash-orchestrator/scripts/update.mjs"
```

The release package names are `pro-flash-orchestrator-antigravity-v0.7.4.zip` and `pro-flash-orchestrator-codex-v0.7.4.zip`. Native Codex UI upgrades have not been live-validated and are not claimed as fully usable.
