- 批量补丁现在检查所有目标路径（包括移动目标），并发状态更新与配额重置使用一致的锁和轮次边界，避免丢失状态或绕过限制。

Fixed cold-start role detection and Claude harness detection, complete batch-patch path checks, locked session bookkeeping and turn-scoped quotas, large command-output guards, and read-only mode.json access. Installation now uses an explicit runtime allowlist, preserving user state while keeping Git history, tests and build tooling in a separate maintenance checkout.

## 安装与更新 / Installation and updates

下载 `pro-flash-orchestrator-v0.5.1.zip`，解压后将其中的 `pro-flash-orchestrator/` 文件夹放入插件安装区域。覆盖旧版本时保留 `.state/`。

需要维护、测试或持续更新时，使用 GitHub 源码仓库，在独立工程目录运行 `node scripts/install.mjs --target <插件安装目录>`。本版本的 ZIP 是精简运行包；完整源码可通过下方 GitHub Source code 下载。

Extract the runtime ZIP into the plugin installation area and keep any existing `.state/` directory. For development, clone the repository into a separate maintenance directory and deploy with `node scripts/install.mjs --target <installation-directory>`.
