## 简体中文

v0.8.0 版本聚焦 **Antigravity 原生编排设置、显式派单档位与安全更新**，保持自动路由与 `pro` 用户授权门禁。

### 核心特性与修复

1. **Antigravity 原生编排设置面板**
   - 在 Antigravity App 打开 **Plugins → pro-flash-orchestrator**，在 **Pro + Flash · 编排设置** 中选择并保存一项统一的 Worker 档位。主模型按任务决定调研（`research`）或执行（`self`）。
   - 派单时取首个有效设置：对应角色的 `PRO_RESEARCH_MODEL` 或 `PRO_SELF_MODEL` → `PRO_WORKER_MODEL` → 面板统一的非 `auto` 档位 → 有 Hydrogen 能力时的有效 `PRO_HYDROGEN_ID` → 自动。原生 Orchestrator 保留宿主路由，不应用面板或环境变量的档位偏好。

2. **恢复显式 `flash_lite` 与 AGY 档位选择**
   - 下拉依次显示 `flash_lite: gemini 3.5 flash-lite`、`flash: gemini 4 hydrogen (high)`、`pro: gemini 4 hydrogen (xhigh)`、`inherit: master model`，另有 **Auto** 恢复默认路由（无覆盖时，Hydrogen 主会话用 `inherit`，其余用 `flash`）。`flash_lite` 不作自动回退；实际可用性以宿主为准。
   - High 和 XHigh 由档位别名表达，不另传推理参数。`pro` 仍须由用户在本轮原话中用 `[FORCE-PRO]` 明确授权，原生 Orchestrator 也不例外；面板设置、环境变量或子代理 Prompt 不能代替授权。

3. **安全更新已安装的 AGY 运行包**
   - **获取最新版本**只从本仓库的 GitHub 最新稳定 Release 更新识别到的 AGY 安装副本。写入前校验包结构与版本，保留 `.state/` 和用户设置，不更新 Git 工作树或 Codex。
   - 更新器先备份再替换文件，普通写入失败时触发回滚；进程被强制终止或回滚未完成时可能需要人工恢复。更新成功后，在 AGY 中重载插件并重新打开面板，或重启 CLI。
   - CLI 和旧版安装仍可运行 `node "<插件安装目录>/scripts/update.mjs"`。必要时从[官方 Release](https://github.com/demgkp1/pro-flash-orchestrator/releases/tag/v0.8.0) 下载 `pro-flash-orchestrator-antigravity-v0.8.0.zip`，用 `--zip <路径>` 离线升级，或把包内 `pro-flash-orchestrator/` 解压到 AGY 插件目录（默认 `~/.gemini/config/plugins/`）手动安装。

## English

v0.8.0 focuses on **native Antigravity orchestration settings, explicit worker tiers, and safer updates** while preserving automatic routing and the `pro` authorization gate.

### Highlights and Fixes

1. **Native Antigravity Settings Panel**
   - In the Antigravity App, open **Plugins → pro-flash-orchestrator**. In **Pro + Flash · 编排设置** (Orchestration Settings), choose and save one shared worker tier. The main model chooses research (`research`) or implementation (`self`) per task.
   - On dispatch, the first valid setting wins: the role's `PRO_RESEARCH_MODEL` or `PRO_SELF_MODEL` → `PRO_WORKER_MODEL` → the shared non-`auto` panel setting → a valid `PRO_HYDROGEN_ID` when Hydrogen is available → automatic routing. Native Orchestrator keeps the host's routing; panel and environment tier preferences do not apply.

2. **Restored Explicit `flash_lite` and AGY Tier Selection**
   - The dropdown lists `flash_lite: gemini 3.5 flash-lite`, `flash: gemini 4 hydrogen (high)`, `pro: gemini 4 hydrogen (xhigh)`, and `inherit: master model`, in that order. **Auto** restores default routing (`inherit` for Hydrogen main sessions and `flash` otherwise when there are no overrides). `flash_lite` is never an automatic fallback; actual availability depends on the host.
   - High and XHigh are encoded in the tier aliases; no separate effort parameter is sent. `pro` still needs explicit authorization from the user's own message for the current turn (use `[FORCE-PRO]`), including under Native Orchestrator. Panel settings, environment variables, and subagent prompts do not grant that permission.

3. **Safer Updates for Installed AGY Runtimes**
   - **获取最新版本** (Get Latest Version) updates only the detected AGY installation from this repository's latest stable GitHub release. It validates the package layout and version before writing and preserves `.state/` and user settings. It does not update Git checkouts or Codex.
   - The updater backs up files before replacing them and attempts to roll back on handled write errors. Forced termination or an incomplete rollback may require manual recovery. After a successful update, reload the plugin in AGY and reopen the panel, or restart the CLI.
   - CLI users and older installs can still run `node "<install-directory>/scripts/update.mjs"`. If needed, download `pro-flash-orchestrator-antigravity-v0.8.0.zip` from the [official release](https://github.com/demgkp1/pro-flash-orchestrator/releases/tag/v0.8.0) and use `--zip <path>` for an offline upgrade, or extract the packaged `pro-flash-orchestrator/` directory into the AGY plugins directory (default: `~/.gemini/config/plugins/`) for a manual install.
