## 简体中文

v0.7.6 版本聚焦 **模型路由枚举清理与主会话路由一致性修复**，彻底移除 `flash_lite` 防止降级，恢复 `Gemini 4 Neon` 默认路由 `"flash"`，并统一规范文档、启动状态卡与跨平台环境变量回退链。

### 核心特性与修复

1. **彻底移除 `flash_lite` 枚举（防止降级至 3.5 Flash-Lite）**
   - 从 `scripts/lib.mjs` 的 `INVOCABLE_SUBAGENT_MODELS` 合法枚举白名单中移除 `flash_lite`，仅保留 `inherit`、`flash`、`pro`。
   - 环境变量（`PRO_RESEARCH_MODEL`、`PRO_SELF_MODEL`、`PRO_WORKER_MODEL`、`PRO_HYDROGEN_ID`）若传入 `flash_lite` 等非白名单值，将按回退链安全回落至 `"flash"`（`Hydrogen` 主会话回落至 `"inherit"`），避免子代理降级至 Gemini 3.5 Flash-Lite。

2. **恢复 `Gemini 4 Neon` 默认路由 `"flash"`**
   - 修复 `targetWorkerModel` 路由策略：`Gemini 4 Neon`、`Argon`、`Carbon` 主会话默认路由至 `"flash"`（映射至 `Gemini 4 Hydrogen High`），仅 `Hydrogen` 主会话默认使用 `"inherit"`。
   - 修复 `scripts/session-start.mjs` 启动卡片模型标签展示，避免非 `Hydrogen` 主会话误显示 `Gemini 4 Hydrogen` 或 `Model="inherit"`。

3. **统一规则/技能模板与跨平台回退链一致性**
   - 同步更新 `plugin.json`、`AGENTS.md` / `rules/AGENTS.md`、`SKILL.md` / `skills/flash-dev/SKILL.md`、`adapters/codex/flash-dev/SKILL.md` 与双语 `README`，消除模板与说明中的 `inherit` / `flash_lite` 自相矛盾表述，统一默认派单示例为 `Model="flash"`（仅 `Hydrogen` 主会话使用 `Model="inherit"`）。
   - 对齐 `session-start`、`codex-hook` 与跨平台环境变量回退链行为与能力路由测试覆盖。

4. **完整继承 v0.7.5 / v0.7.4 全部能力**
   - 保留 Codex 稳定 Git Marketplace 与事务式迁移、纯只读 `research` 双轨验收契约、独立 `currentBatchResearchSpawns` 与 `[MULTI-RESEARCH]` 追踪、动态 `PLUGIN_VERSION`、死循环熔断、Audit 动态切片配额与免 Git 一键升级（`scripts/update.mjs`）。

## English

v0.7.6 focuses on **subagent model enum cleanup and routing consistency**, removing `flash_lite` to prevent model downgrades, restoring default `"flash"` routing for `Gemini 4 Neon` main sessions, and aligning templates, startup cards, and cross-platform fallback chains.

### Highlights and Fixes

1. **Removed `flash_lite` Enum to Prevent Downgrade to 3.5 Flash-Lite**
   - Removed `flash_lite` from `INVOCABLE_SUBAGENT_MODELS` in `scripts/lib.mjs`, leaving only `inherit`, `flash`, and `pro`.
   - Invalid or removed enum overrides (including `flash_lite` via `PRO_RESEARCH_MODEL`, `PRO_SELF_MODEL`, `PRO_WORKER_MODEL`, or `PRO_HYDROGEN_ID`) safely fall back to `"flash"` (or `"inherit"` on `Hydrogen` main sessions), preventing accidental downgrades to Gemini 3.5 Flash-Lite.

2. **Restored `Gemini 4 Neon` Default Routing to `"flash"`**
   - Updated `targetWorkerModel` so `Gemini 4 Neon`, `Argon`, and `Carbon` main sessions route subagent dispatches to `"flash"` (`Gemini 4 Hydrogen High`) by default; only `Hydrogen` main sessions default to `"inherit"`.
   - Fixed `scripts/session-start.mjs` startup card routing text so non-`Hydrogen` sessions no longer misreport `Gemini 4 Hydrogen` or `Model="inherit"`.

3. **Unified Templates, `session-start`, `codex-hook` & Env Fallback Chain**
   - Synchronized `plugin.json`, `AGENTS.md` / `rules/AGENTS.md`, `SKILL.md` / `skills/flash-dev/SKILL.md`, `adapters/codex/flash-dev/SKILL.md`, and bilingual READMEs to use `Model="flash"` as the default dispatch example (noting `Model="inherit"` for `Hydrogen` main sessions only) and removed contradictory `flash_lite` / `Neon -> inherit` references.
   - Aligned `session-start`, `codex-hook`, environment variable fallback chains, and capability test coverage.

4. **Preserves All v0.7.5 / v0.7.4 Capabilities**
   - Retains the stable Codex Git marketplace release, transactional migration, strictly read-only `research` dual-track acceptance contracts, dedicated `currentBatchResearchSpawns` & `[MULTI-RESEARCH]` tracking, dynamic `PLUGIN_VERSION`, thrashing circuit breaker, Audit slice quota, and git-free upgrades (`scripts/update.mjs`).
