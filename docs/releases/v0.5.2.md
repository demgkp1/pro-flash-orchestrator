## Codex adapter and release packaging / Codex 适配与发布打包

v0.5.2 adds an independent Codex local-marketplace package while retaining the Antigravity runtime package. The release assets are:

- `pro-flash-orchestrator-antigravity-v0.5.2.zip`
- `pro-flash-orchestrator-codex-v0.5.2.zip`

The Codex ZIP is standalone: extract `pro-flash-orchestrator-codex/`, run `node install.mjs`, review all six hooks, configure a worker, and run `node doctor.mjs --verify-worker`. Uninstall with `node install.mjs --uninstall`. Registration uses the official Codex marketplace/plugin CLI rather than cache mutation.

本版本新增独立的 Codex 本地 Marketplace 运行包，同时保留 Antigravity 运行包。Codex ZIP 解压后可直接运行 `node install.mjs`，由用户审阅六个 Hook 后再配置并真实验证助手模型；使用 `node install.mjs --uninstall` 注销。安装过程调用 Codex 官方 Marketplace/插件注册命令，不修改插件缓存。

## Codex compatibility and verification / Codex 兼容与验证

Codex CLI `0.167.0-alpha.3.2` did not load bundled plugin hooks in the acceptance environment. The installer therefore connects six user-native hook events through `CODEX_HOME/hooks.json`, preserving unrelated entries and hashing the runtime into each generated command so code changes require review again.

The user reviewed all six hooks as trusted and a real desktop `PreToolUse` event was observed. The distributed candidate remains `gpt-6-luna` with low reasoning effort, but it returned HTTP 503 in that environment and remains blocked until it verifies. The user's local `gpt-5.6-sol`/low selection completed the minimal AgentRouter-backed real request successfully. No main-model fallback occurs after failed verification.

在验收环境中，Codex CLI `0.167.0-alpha.3.2` 未加载插件内置 Hook，因此安装器将六个用户级原生 Hook 合并到 `CODEX_HOME/hooks.json`，保留其他 Hook，并把运行时代码哈希写入命令；代码变化后必须重新审阅。用户已将六个 Hook 审阅为 trusted，且真实桌面会话已观察到 `PreToolUse`。默认候选 `gpt-6-luna`/low 在该环境返回 HTTP 503；用户本地改用 `gpt-5.6-sol`/low 后，AgentRouter 的最小真实请求验证成功。

Live acceptance exposed flattened collaboration tool names and the CLI-specific `collab_tool_call` event format. The adapter now normalizes supported dotted/flattened tool names, preserves the native model/message/context arguments, and correctly keeps a root agent whose agent ID equals its session ID subject to root edit limits. Windows metadata replacement uses bounded retries and still denies recognizable tool execution on persistent failure.

Real ordinary writes, atomic batch add/update/delete/move refusal, large-output refusal, and explicit unavailable-model failure have evidence. Native worker requests still fail with `response.failed`, including a no-tool PING probe. The alternate `gpt-5.6-luna`/low candidate returned HTTP 503 with no AgentRouter channel and was not enabled. The complete worker contract/context/recursion/wait/close lifecycle and a new desktop-session acceptance run remain pending; this draft release is blocked until required acceptance passes.

Account sign-in and Claude Code are not live-validated. Hosted tools, hook errors/timeouts, and later input to an already-approved interactive shell remain acknowledged coverage gaps. See [Codex acceptance report](../codex-acceptance-v0.5.2.md) for the evidence and open checklist. These limitations mean v0.5.2 is not yet claimed as fully live-usable on Codex.

真实验收发现的扁平工具名、CLI 协作项目格式和根代理角色误判已修复；Windows 元数据替换增加有限重试，持续失败仍拒绝可识别的工具执行。普通写入、批量 add/update/delete/move 原子拒绝、大输出拒绝和不可用模型显式失败已有真实证据。原生助手连无工具 PING 都返回 response.failed；替代候选 gpt-5.6-luna/low 返回 HTTP 503 无渠道，未启用。完整助手契约/上下文/递归/wait/close 闭环和新桌面会话仍待验收，本发布草案在必需验收通过前保持阻塞。

账户登录与 Claude Code 尚未进行真实验证。Hosted tools、Hook 错误/超时及已批准交互 Shell 的后续输入仍属于已知覆盖缺口。因此本版本不宣称 Codex 已完整可用，证据与待办见上述验收报告。

## Public CI and version policy / 公共 CI 与版本策略

Public CI runs 162 offline assertions: 90 doctor checks, 25 regressions, 7 install/package checks, and 40 Codex protocol/evidence/package checks, plus concurrency stress. It builds both platform archives and verifies their independent roots and exact allowlists. Public CI does not make provider/API requests; real worker verification remains a local acceptance step.

公共 CI 的 162 项离线断言由 90 项 doctor、25 项回归、7 项安装/打包与 40 项 Codex 协议/证据/打包检查组成，另运行并发压测；两个平台 ZIP 会分别校验根目录与精确白名单。公共 CI 不调用模型提供商 API，真实助手验证由本地验收完成。

The remaining `0.5.x` line is reserved for Codex and Claude adapter fixes. Unrelated new features should target a later version series.

后续 `0.5.x` 仅接收 Codex 与 Claude 适配修复；其他新功能应进入更高版本系列。
