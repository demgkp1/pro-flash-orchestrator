# v0.6.1

本次发布完成全仓审查，并将此前工作区中的跨平台适配和 v0.6 功能统一收尾。

- Antigravity 使用合法模型枚举：Hydrogen 主会话继承 `inherit`，其他主会话默认 `flash`；显式环境配置与能力检查保持优先。启动 capabilities 探测、Flash 主模型宽松策略、原生 Orchestrator Lite Guard Mode 与 Audit 配额均保留。
- 父会话关联支持转录 sender、派单契约 `[PRO-PARENT:<id>]` 和 last_spawn.json。多个候选父会话不再按时间猜选；旧版单条 spawn 状态可迁移，父子命令证据保持同步。
- 同批源码文件在父 Session 锁内原子认领，多文件冲突不留下部分认领。无法关联 AGY 父会话、状态损坏或持久化失败时拒绝源码写入；失败状态写入不再返回虚假成功，临时文件会清理。
- report 复用 STATE_DIR / LOG_FILE，准确区分轮询、并发、递归、文件冲突、配置保护与状态失败。省流面板按实际请求与保留区间估算 KB / Token，排除 shadow 假设节省、无效记录及无效日期窗口。
- Codex 独立包包含 `node report.mjs` 入口，无需提前设置宿主环境变量；原生 `list_agents` 及别名统一执行轮询守门。当前可选模型仍须同时满足原生工具目录与提供方验证；已有用户 Worker 配置保持不变。
- 根 SKILL.md / AGENTS.md 与规范目录同步，发布测试检查镜像、版本与 Matcher 一致性。安装测试确认本地 capabilities.json 被保留且不进入发布包；doctor 末尾重新读取真实宿主能力摘要，并发测试退出时清理临时状态。

完整离线验收与文件清单见 [本次全仓审查记录](https://github.com/demgkp1/pro-flash-orchestrator/blob/v0.6.1/docs/audit-v0.6.1.md)。离线通过不代替真实宿主验收：Codex 原生子代理曾遭遇上游不可用，完整原生派发闭环、Claude Code 与账户登录仍需真实验证。
